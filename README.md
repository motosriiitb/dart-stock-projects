# Dart Stock Projects

Small Dart CLI projects around the stock market.

| Project | What it does |
|---|---|
| pnl_calculator | Net profit/loss on a trade with brokerage |
| sma_calculator | Moving averages and a simple signal |
| sip_calculator | Future value of a monthly SIP |
| portfolio_tracker | Holdings and total P&L (saved to JSON) |
| watchlist | Target price watchlist (saved to JSON) |

Each folder has its own `main.dart` and README. Run with `dart run main.dart`.
